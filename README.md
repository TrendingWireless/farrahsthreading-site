# Farrah's Threading & Beauty Studio — website

Static site for https://farrahsthreading.com (Lancaster, PA). Hosted on GitHub Pages from the `main` branch; the DNS lives at Squarespace.

- The files in this top level are the **built** site (what visitors see). Don't hand-edit them for anything beyond a quick typo: they're overwritten on the next build.
- The **source** is in [`src/`](src/README.md), with instructions for rebuilding.
- Easiest way to change anything: open this repository in Claude and describe the change; it edits the source, rebuilds, and pushes.

Appointment and gift-card requests go through Jotform (links in `src/index.html` → `SITE.bookingUrl` / `SITE.giftCardUrl`).
